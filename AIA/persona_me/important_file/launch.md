# Lancement de N8N avec Docker Compose

## Lancer en arrière-plan

```bash
sudo docker-compose up -d
```

## Voir les logs

```bash
sudo docker-compose logs -f
```

## Arrêter proprement

```bash
sudo docker-compose down
```

## Accès

Ouvrez votre navigateur sur [http://localhost:5678](http://localhost:5678)
