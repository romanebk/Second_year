📌 Note technique

Ces 3 animations sont en CSS pur (zéro dépendance, fonctionnent partout, super légères). Pour la version finale en Next.js, on peut soit garder le CSS, soit passer à React Three Fiber + @react-three/drei pour des dés vraiment 3D avec ombres réalistes, matériaux PBR, particules — encore plus impressionnant mais plus lourd.

  • Cube 3D CSS = bon compromis poids/qualité, parfait pour PWA mobile
  • Carte flip = la plus rapide visuellement, idéale si on enchaîne des tours
  • Slot machine = la plus "casino", parfaite pour le mode Crescendo qui monte en intensité
  • React Three Fiber = à envisager si on veut "wow" max sur desktop, mais peut être lourd sur vieux téléphones
