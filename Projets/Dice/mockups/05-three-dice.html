📊 Three.js vs CSS — coût technique

Le rendu 3D Three.js coûte plus cher que les animations CSS, mais offre un niveau de polish inatteignable autrement. Voici les chiffres concrets pour aider à décider :

📦 Poids Three.js

~150 ko
Gzippé. Lazy-loadable uniquement quand on entre dans une partie. Cache après 1ère visite.

⚡ Perfs mobile

60 fps
Sur tout iPhone ≥ 2017 et Android moyen-haut. Ombres soft activables/désactivables.

🎨 Wow factor

★★★★★
Vraies ombres, matériaux PBR, caméra interactive. Sensation produit "premium".

Ma reco : on part sur Three.js (via React Three Fiber dans Next.js) pour le wow factor. On ajoute un fallback CSS automatique pour les vieux téléphones (détection WebGL au démarrage). Best of both worlds.
